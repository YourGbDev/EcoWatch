# Smart Flood & Waste Monitoring Platform

## Problem Statement

Communities often experience environmental issues such as:

- Flooding
- Illegal dumping
- Clogged drainage
- Uncollected garbage

There is no centralized platform where citizens can easily report these issues and monitor their resolution status.

---

## Users

### Citizen

Can:

- Register
- Login
- Submit reports
- View report history

### Administrator

Can:

- View reports
- Manage reports
- Update status
- View statistics

---

## MVP Features

- User Authentication
- Report Submission
- Report Tracking
- Admin Dashboard
